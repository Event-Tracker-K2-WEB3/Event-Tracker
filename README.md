# Event-Tracker


## 📌 Overview
Event Tracker is a web application designed to manage and organize events online. It allows users to create, track, and participate in events through a modern and intuitive interface.

## 🛠️ Tech Stack
- **Backend:** Spring Boot  
- **Frontend:** Next.js  

## 👥 Team
This project is developed by a team of **four members**:
- 2 Backend Developers (Spring Boot)
- 2 Frontend Developers (Next.js)

## 🎯 Objective
The goal of this project is to build an online event management system where users can:
- Create and manage events  
- Track event details and schedules  
- Interact with participants  

## 🚧 Status
The project is currently under development.

## 🧩 Architecture
- The backend handles APIs, business logic, and database operations.  
- The frontend provides a responsive and dynamic user experience.  

## 🤝 Collaboration
The project is developed collaboratively using version control and modern development practices.

**Event Tracker** aims to simplify online event management using modern technologies and a clean architecture.
